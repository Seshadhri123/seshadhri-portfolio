# Seshadhri Murugavel — Portfolio

A personal portfolio built with React and Vite. It brings together selected technical projects, research notes, learning milestones, leadership work, a character-and-film journal, and a downloadable resume.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production-ready output is generated in `dist/`.

## Deployment

This repository is ready for Vercel. Import the GitHub repository in Vercel and keep the detected settings:

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
